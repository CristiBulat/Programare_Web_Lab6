# Legacy React implementation

This folder is the **archived** React 19 + Vite version of Reel.

The active implementation has been rewritten in Angular 18 and lives in [`../angular/`](../angular/).
This code is preserved for git history and lab demonstration purposes.

To resurrect it locally:

```bash
cd legacy-react
npm install
npm run dev
```

…but prefer the Angular version for any new work.
